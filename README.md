# Anna Sarbiewska — strona ekspercka v2

Wersja wizualna oparta na:
- głębokiej zieleni,
- antycznym złocie jako akcencie,
- kremowej i ciepłej bieli,
- autorskiej sesji fotograficznej.

## Główne zdjęcia
- hero.webp — pierwszy ekran, ruch/sprawczość
- about.webp — sekcja ekspercka „O mnie”
- teacher.webp — teacher education
- research.webp — badania / współpraca / speaking
- human.webp — Pedagogika Ludzkim Głosem

## Technicznie
Strona jest statyczna: HTML + CSS + JS. Nie wymaga kreatora stron ani WordPressa.
Może działać na hostingu statycznym; SSL może być bezpłatny.

## Do uzupełnienia przed publikacją
- dokładne linki do profilu UWM / Google Scholar / LinkedIn / Facebook,
- osobna podstrona pełnej bibliografii,
- wersja angielska,
- favicon i grafika social preview,
- polityka prywatności, jeśli pojawi się formularz lub analityka.
